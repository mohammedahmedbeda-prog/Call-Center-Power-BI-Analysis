# 📊 Call Center Power BI Analysis

An interactive **Power BI dashboard** designed to analyze call center performance and provide insights into customer satisfaction, agent performance, and key business metrics.

## 📌 Project Overview

This project focuses on analyzing call center data and transforming it into an interactive dashboard using **Microsoft Power BI**.

The dashboard helps users explore call center performance through interactive visuals and key performance indicators.
